POST
/api/v1/recover/find
Find user for password recovery


Verifies user existence by email, generates a password reset OTP, caches it in Redis, dispatches the OTP email via queue, and returns the user details with a reset password page token.

Try it out
No parameters

Request body

application/json
Example Value
Schema

  "email": "user@example.com"
}

POST
/api/v1/recover/reset
Reset user password



Resets the user password using the reset password page token. Validates password constraints, ensures it differs from the previous password, updates password hash, blacklists the token in Redis, and emits a password reset confirmation email.

Try it out
No parameters

Request body

application/json
